# HH.ru AI Agent (Auto-Responder) 🤖💼

Полностью автономный ИИ-агент для автоматического поиска вакансий на HH.ru, фильтрации мусора и рассылки уникальных сопроводительных писем с помощью локальной нейросети (Llama 3). Отчёты пишет в консоль.

## Фичи
- **Умный парсинг**: обходит Cloudflare и блокировки HH.ru за счет Playwright (сохраняет сессию авторизации, капчу просит ввести в консоли).
- **Двойная фильтрация**: хард-фильтр по стоп-словам + интеллектуальный анализ вакансии через локальную LLM (отсекает нерелевантные вакансии вроде "продажников" и "риелторов", даже если они всплыли в поиске по IT).
- **Кастомные сопроводительные письма**: нейросеть читает ваше резюме и текст вакансии, выдавая идеальное персонализированное письмо для отклика.
- **Анкеты из чатов**: находит в переписке с работодателями ссылки на анкеты и заполняет их, но не отправляет. Проверяете и отправляете вы сами.
- **Работает 24/7**: бесконечный цикл с задержками (по умолчанию 30 минут) позволяет боту работать на вас круглосуточно.

## Требования
- Python 3.9+
- Установленный [Ollama](https://ollama.com/) с загруженной моделью (по умолчанию `llama3` или `llama3:8b`).

## Настройка (Гайд для себя и потомков)

### 1. Установка зависимостей
Склонируйте репозиторий и установите библиотеки:
```bash
pip install -r requirements.txt
playwright install chromium
```

### 2. Настройка окружения
Создайте файл `.env` в корне проекта:
```ini
OLLAMA_URL="http://localhost:11434/api/generate"
OLLAMA_MODEL="llama3"
```

### 3. Настройка поиска под себя
Откройте `config.py` и подстройте логику под своё резюме:
- `SEARCH_QUERIES` — список запросов (например, "Python backend").
- `TARGET_RESUME_NAME` — точное название вашего резюме на HH (чтобы бот выбирал правильное из списка).
- `MY_RESUME_SUMMARY` — подробное текстовое саммари ваших навыков. **Это критически важно**, так как на основе этого текста ИИ будет писать сопроводительные письма. Опишите свой стек, проекты и пожелания максимально подробно.

### 4. Первый запуск (Авторизация)
При самом первом запуске скрипт откроет видимое окно браузера:
```bash
python main.py
```
Вам нужно **вручную войти в свой аккаунт HH.ru** (ввести код из SMS/почты). Как только вы войдете, скрипт сохранит куки в файл `state.json`. После этого можете закрыть скрипт (Ctrl+C).

### 5. Боевой запуск
Запускайте скрипт заново:
```bash
python main.py
```
Теперь браузер запустится в скрытом режиме (headless) и начнет автоматически собирать вакансии.

## Анкеты из чатов
Каждый цикл: поиск и отклики → обход чатов `hh.ru/chat` → заполнение анкет. **Агент анкеты не отправляет никогда**: он доходит до последней страницы и останавливается перед кнопкой «Отправить».

- **Чаты.** Агент читает новые сообщения, печатает сообщения работодателей в консоль и складывает ссылки на анкеты в таблицу `forms` (`agent.db`). Распознаются Google Формы, Яндекс Формы, Typeform, Tally и прочие ссылки, если в сообщении говорится об анкете или форме. Ссылки на Telegram-ботов, документы и главные страницы сайтов не считаются формами.
- **Заполнение.** Поля извлекаются из разметки страницы (label, aria-*, role), ответы даёт локальная Ollama (`FORMS_MODEL`, по умолчанию `qwen2.5:14b`) через JSON-схему. Факты (ФИО, контакты, зарплата, ссылки) берутся только из `profile.yaml`: выдуманные ссылки, email и телефоны отбрасываются. Ответы и скриншоты каждой страницы сохраняются (`forms_shots/`).
- **Вручную.** Формы с входом в Google, капчей, обязательной загрузкой файла или нестандартными обязательными полями агент не заполняет, а помечает статусом `manual`.

Подготовка:
```bash
cp profile.example.yaml profile.yaml   # заполните
ollama pull qwen2.5:14b
```

Когда сядете разбирать анкеты:
```bash
python -m forms.cli list
```
Дальше по каждой анкете:
- `show <id>` — ответы и пути к скриншотам;
- `fix <id> <номер> <текст>` — поправить ответ (галочки через `;`, `-` очищает поле);
- `open <id>` — открывает анкету в видимом браузере и вписывает сохранённые ответы; проверяете и нажимаете «Отправить» сами;
- `done <id>` / `skip <id>` — отметить отправленной или пропустить;
- `refill <id>` — заполнить заново с нуля.

Статусы: `filled` — заполнена и ждёт вас, `needs_input` — не хватило данных для обязательных полей, `manual` — заполнять руками.

Настройки в `.env`: `ENABLE_CHATS`, `ENABLE_FORMS`, `FORMS_MODEL`, `FORMS_MAX_PER_CYCLE`, `CHATS_SCAN_LIMIT`.

## Как изменить локацию поиска?
По умолчанию бот ищет вакансии сначала в Санкт-Петербурге (`&area=2`), а затем удаленку по всей РФ (`&area=113&schedule=remote`).
Вы можете изменить `area` (код региона) в файле `hh_client.py` внутри метода `search_and_apply`.
